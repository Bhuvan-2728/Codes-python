# Codes-python
# First-Year Python CODES

Welcome to mi casa! This is a collection of core Python programs built during my 1st year. 

##  WHATS's INSIDE
* **`NUMBER_GUESSING_GAME.py`** :An interactive CLI game utilizing Python's random module and loop 
                                 structures to handle user inputs, guess validations, and attempt tracking.

* **`CLI_CALCULATOR.py`**       : A functional Command Line Interface calculator implementing
                                  modular arithmetic operations and user-driven conditional menus. 

* **`FILE_ORGANISER.py`**       : A practical automation script using the os and shutil modules 
                                   to scan a directory and automatically sort files into categorized 
                                   folders based on their extensions.

* **`TO_DO_LIST.py`**           : A task-management script utilizing lists/dictionaries to allow users
                                   to dynamically add, view, and delete daily tasks via the terminal.

* **`PASSWORD_GEN.py`**         : A security-focused script that leverages the string and secrets 
                                  (or random) modules to generate strong, randomized, and customizable
                                  alphanumeric passwords.

* **`QUIZ.py`**                 :  A multi-choice quiz application utilizing structured data to 
                                   track user scores, evaluate answers, and provide real-time performance feedback.
